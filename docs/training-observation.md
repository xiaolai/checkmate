# Training: beginner observation worksheet

Written before any pilot observation, as the plan requires. Automated gates verify behaviour, not usability or learning. Until a beginner has been observed with this worksheet, report usability and learning effect as **not verified**.

## Who and how

- One beginner who knows how the pieces move but does not play regularly. Record age band and prior chess experience only; no names or other personal data.
- A build with `CHECKMATE_TRAINING_ENABLED=1`, a fresh data directory, voice and companion off.
- The observer does not explain the exercises. Note when the learner asks for help, and what help was given; that help is outside the app and the app cannot see it.

## Tasks

| # | Task | Watch for | Notes |
| --- | --- | --- | --- |
| 1 | Open Training from the sidebar and choose any exercise | Finds the library; understands "New" versus "Existing game" | |
| 2 | Reach the Target, twice | Reads the move count; uses drag or clicks; reaction to a blocked move | |
| 3 | Find the Attackers, including a board where the answer is None | Understands select-then-Submit; finds None | |
| 4 | Mate in One | Reaction to a legal non-mating move; promotion choice if offered | |
| 5 | King Safe Squares and Escape Check | Understands "covered" squares; reaction to a rule-error answer | |
| 6 | Check, Mate or Stalemate? | Confuses stalemate with checkmate? | |
| 7 | Pawn Duel from the library, then back to Training | Notices the simplified rules label | |
| 8 | Use a hint, then read the result label | Understands "first try · no recorded help" versus "with recorded help" | |
| 9 | Increment B (also set `CHECKMATE_TRAINING_B=1`): Save Your Piece and Capture Wisely | Defence or capture reasoning; reaction to the shown refutation after a wrong move | |
| 10 | Special Moves: a castling question, a promotion (including Cancel) and en passant | Castling and en-passant understanding; finds the promotion chooser | |
| 11 | Simple Tactics: spot a fork, then win with one | Tells recognising a fork from winning with it | |
| 12 | Finish the Game with a queen | Stalemate avoidance; waits for the defender; reaction to a draw claim offer | |
| 13 | Mixed Practice, three cases, then a short Guided Game ended by choice | Works out what matters without a topic label; reads habit notes as advice, not errors; tries a moment again | |
| 14 | A related lesson from the library, then back to Training | Finds the way back; does not lose their place in the course | |

## Record

For each task: completed (yes/no), time, hints used, every moment of visible confusion (quote the learner when possible), and anything the learner said about the labels or feedback. Summarise the three biggest sources of confusion and file each as a follow-up before claiming usability.
