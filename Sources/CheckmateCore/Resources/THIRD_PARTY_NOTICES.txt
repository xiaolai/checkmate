packaged separately and unmodified. The sf_19 README lists the .nnue file as
part of the Stockfish distribution, which it licenses under the GNU GPL
version 3; the network is distributed under those terms. The README also
states that Stockfish's networks are trained on data from the Leela Chess Zero
project, made available under the Open Database License (ODbL):
https://opendatacommons.org/licenses/odbl/odbl-10.txt
NNUE_EMBEDDING_OFF changes packaging only, not evaluation or search.

Distribution retains corresponding source/build/network materials and GPL notices.
